# README
The Logic Chip Tester is a project with the purpose of creating a test facility for all the ICs that I've used throughout the years.

When it is done it will be able to test a number of ICs and allow anyone to verify if all the gates in their ICs are working. 
I'm making this because testing ICs by hand is slow and frankly some of my ICs have bent pins, have been exposed to high heat, have frozen, gotten wet 
and who knows what whilst I took them to class and back. So I want to see if they still work or not. I figured this might help someone out there as well.


**The program is still work in progress**
